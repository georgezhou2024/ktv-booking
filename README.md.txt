# KTV客户预订管理系统
> 轻量预订管理工具，适合PR管理KTV包厢预约，记录客户、包厢、时段、人数、套餐低消、金额、备注。
> 纯前端，无需数据库，数据保存在浏览器本地，支持导出备份。

## ✨功能
- 新增预订：客户姓名、电话、预订日期、包厢类型、时段、到场人数、套餐/低消、金额、备注
- 防撞单校验：同一日期+包厢+时段不能重复保存，防止撞包厢
- 按客户名 / 包厢搜索，按日期筛选订单
- 编辑、删除预订记录
- 导出JSON备份数据

## 🚀使用方式
1. 访问 Github Pages 链接
2. 填写表单，点保存预订
3. 支持搜索、筛选订单
4. 定期导出备份，防止浏览器数据丢失

## ⚠️注意
数据存储在浏览器本地 localStorage，换电脑/清除浏览器缓存会丢失记录，**务必定期导出备份文件**。
