# 隐序威士忌与雪茄俱乐部

一个以原生 HTML、CSS 和 JavaScript 构建的中文品牌展示网站，可直接部署到 GitHub Pages，无需安装构建依赖或运行后端。

## 页面

- `index.html`：响应式品牌主页，介绍俱乐部理念、品饮体验、空间、示例藏品，并提供预约意向整理与复制功能。
- `menu.html`：原有 PH 玩家俱乐部门店酒水单，保留门店切换与酒单分类。
- `assets/`：为新品牌主页本地托管的概念摄影素材。

## 本地查看

在仓库根目录启动任意静态文件服务器后，打开 `/` 即可预览主页。例如：

```sh
python -m http.server 8000
```

**预约说明：** 表单只在浏览器中整理到访意向，并允许访问者复制预约内容；项目没有预约后端，也不会自动向门店发送资料。隐序是示例品牌，营业地址、营业时间和藏品信息须以实际经营信息替换。
